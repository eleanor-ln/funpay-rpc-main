# FunPay RPC

Десктопное приложение FunPay с Discord Rich Presence, пользовательскими темами и Windows-уведомлениями.

English version: [README.en.md](README.en.md)

## Возможности

- активность Discord RPC;
- Stylus;
- загрузка CSS-тем из папки;
- загрузка звуков уведомлений из папки;
- Windows-уведомления с ником отправителя и содержимым сообщения;
- встроенная тема от разработчика.
- Окно настроек открывается клавишей `F1`.

## Запуск из исходников

Требуется Node.js 20 или новее, только для запуска из исходников!!!

```text
npm install
npm run dev
```

Темы и звуки
В режиме разработки используйте папки:

```text
themes/
sounds/
```

После добавления файла нажмите `Refresh` в настройках, затем выберите его в списке. Кнопка `Open folder` открывает нужную папку в Проводнике.

Поддерживаются CSS-файлы и звуки `MP3`, `OGG`, `WAV`, `M4A`, `AAC`, `FLAC`.

## Сборка установщика Windows

```text
npm run build-win
```

Установщик появится в папке `build/`. При первом запуске встроенная тема копируется в пользовательскую папку тем и может быть выбрана в настройках.
