# FunPay RPC

Десктопное приложение для FunPay с Discord Rich Presence, пользовательскими темами и Windows-уведомлениями.

English version: [README.en.md](README.en.md)

## Возможности

- активность Discord RPC по аналогии с Activities FunPay;
- встроенный Stylus для управления пользовательскими стилями;
- загрузка CSS-тем из папки `themes`;
- загрузка звуков уведомлений из папки `sounds`;
- переключатели звуковых и Windows-уведомлений;
- Windows-уведомления с ником отправителя и содержимым сообщения;
- иконка приложения на основе официального логотипа FunPay;
- первая тема `funpay.EleanorMay-theme.css` уже включена в комплект.

## Запуск из исходников

Требуется Node.js 20 или новее.

```text
npm install
npm run dev
```

Окно настроек открывается клавишей `F1`.

## Темы и звуки

В режиме разработки используйте папки:

```text
themes/
sounds/
```

После добавления файла нажмите `Refresh` в настройках, затем выберите его в списке. Кнопка `Open folder` открывает нужную папку в Проводнике.

Поддерживаются CSS-файлы и звуки `MP3`, `OGG`, `WAV`, `M4A`, `AAC`, `FLAC`. CSS-темы могут содержать блок `@-moz-document` и загружаться на Userstyles.

## Сборка установщика Windows

```text
npm run build-win
```

Установщик появится в папке `build/`. При первом запуске встроенная тема копируется в пользовательскую папку тем и может быть выбрана в настройках.
